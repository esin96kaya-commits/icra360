# İcra360 marka ve tasarım sistemi

Ürün adı kullanıcıya **İcra360** olarak gösterilir. Teknik tanımlayıcılarda Türkçe karakter kullanılmaz: `icra360`, `Icra360`, `@icra360`.

## Anlam

- **360:** Tebligat yüklemeden cevap yazısı ve maaş kesintisine kadar uçtan uca süreç.
- Slogan: Personel icra süreçleri tek yerde.
- Açıklama: İşverenler için personel icra tebligatı, cevap yazısı ve maaş kesintisi takip sistemi.

## Logo seti

Kaynak: `apps/web/public/brand/`

| Dosya | Kullanım |
| --- | --- |
| `logo-horizontal-light.svg` | Açık zemin, kenar çubuğu ve giriş |
| `logo-horizontal-dark.svg` | Lacivert/koyu zemin, e-posta üst bilgisi |
| `icon-light.svg` | Kare ikon, açık zemin |
| `icon-dark.svg` | Kare ikon, koyu zemin |
| `../favicon.svg` | Tarayıcı simgesi |

İşaret: belge + döngü/onay. “360” süreci belge üzerinde teal onay yayı ile temsil eder.

## Metin kullanımı

- Tarayıcı başlığı: İcra360
- Varsayılan belge üst bilgisi: İcra360
- E-posta gönderen adı: İcra360 (`MAIL_FROM_NAME`)
- Paketler: `@icra360/*`
- Veritabanı / Docker: `icra360`
